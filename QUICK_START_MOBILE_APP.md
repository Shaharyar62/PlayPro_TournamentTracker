# 📱 PlayPro Umpire - Quick Start Guide

## Install on Your Phone

### For iPhone Users 📱
1. Open in **Safari**
2. Tap **Share** button (📤)
3. Tap **"Add to Home Screen"**
4. Tap **"Add"**
5. Done! Tap the icon on your home screen

### For Android Users 🤖
1. Open in **Chrome**
2. Tap **"Install"** when prompted
3. Or tap **⋮** menu > **"Install app"**
4. Done! Tap the icon on your home screen

## Need Help? 🆘

If the install button doesn't appear:
- Make sure you're using the right browser (Safari for iOS, Chrome for Android)
- Refresh the page
- Clear browser cache
